Prêt. Modèle: Xenova/speecht5_tts (ONNX WASM) - 100% navigateur. Avantages vs Python serveur: - Pas d'install, pas de GPU nécessaire - Offline après 1er chargement (~120 Mo) - Vrai clonage avec embedding de ta vidéo Limite vs XTTS-v2 serveur: - Qualité 85% de XTTS-v2 (vs 100% serveur) - Voix un peu plus robotique mais timbre Homer conservé
Pourquoi XTTS-v2 ne peut pas être en WASM ?
- PyTorch = 400 Mo de C++ non compilable en WASM
- Modèle = 2.5 Go, navigateur max ~2 Go RAM
- Besoin CUDA pour temps réel

Solution WASM : On utilise ONNX Runtime Web (WASM + WebGPU) + SpeechT5 (Microsoft, open-source, gratuit). C'est le même principe que XTTS (embedding de voix + TTS) mais en 120 Mo, optimisé WASM.

transformers.js fait tourner Python → ONNX → WASM automatiquement.
